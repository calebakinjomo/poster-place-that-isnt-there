VELDARA — a travel poster for a place that does not exist. A desert that only blooms after dark: by day it is ordinary dunes, but at night giant luminous moonflowers open across the sand under a huge low amber moon. A Node 22 program draws the poster entirely in code — deep indigo sky scattered with stars, the amber moon, three layered gold dunes, one colossal night-bloom ringed by drifting luminous pollen, smaller blooms waking across the dunes, and a tiny lantern traveller walking the ridge toward the flower. The place's name is set large across the lower third in a bold wood-type display face drawn by hand.

## Run it

```sh
node main.ts
```

Writes one 1024x1024 PNG to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Node 22+ standard library only, no network, deterministic — two runs produce byte-identical output.
